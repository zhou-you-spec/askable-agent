# 问不出口的那道题

> 一个不会嘲笑你的实训答疑助教。档位永远由学生拨。

面向高职实训课的 AI 答疑智能体。它不急着给答案，而是先接住学生，再按学生自己选择的深度，一点点把题讲明白。

## 三个"不"

1. **不直接给答案** —— 1 档只给思路，学生不动手，它不越位
2. **不嫌问题简单** —— 同一个问题问十遍它照讲；讲不懂就**换个讲法**再讲
3. **不问你是谁** —— 不收姓名学号，聊完就走

## 核心机制：3 × 3

| 求助深度 \ 讲解粒度 | 逐行讲 | 只讲卡住的 | 只给代码 |
| --- | --- | --- | --- |
| 3 档 完整代码 | 每行配类比 | 只点卡点 | 只贴代码 |
| 2 档 关键一行 | - | 只指一行 + 类比 | - |
| 1 档 只给思路 | - | 一个具体问题 | - |

同一道题最多 9 种讲法，但**档位永远由学生拨**：说"再给点提示"升一档，亲口说"我放弃了"才给完整代码。

## 三门课程，一套机制

`courses/` 下每门课一个知识包（报错 / 概念 / 类比 / 教案四份 JSON），换课只换文件，机制完全不动：

| 课程 | 报错 | 类比 | 概念 | 教案 |
| --- | --- | --- | --- | --- |
| Python 数据分析与建模 | 10 | 24 | 12 | 6 |
| Excel 数据处理与分析 | 6 | 8 | 6 | 4 |
| 会计电算化 | 5 | 8 | 6 | 4 |

非代码课程（Excel / 会计）里，"完整代码"自动变成"完整处理步骤"，逐行讲解变成逐步核对。

## 它真的会教（不只是会答）

- **多轮引导**：1 档先问一个具体问题 → 学生答"在桌面" → 它接着追问"代码运行时去哪里找这个文件" → 再给可执行的第一步。全程不给代码。
- **换讲法**：3 档说"还是没懂"，它切换讲解粒度、换一种说法重讲，而不是重复。
- **学会反馈**：学生说"懂了"，它记下"已掌握"，并留一道下一步挑战。
- **降低开口门槛**：学生说"我不敢问"，它不追问细节，只让把报错整段复制过来。
- **语音输入**：说不出口的时候，按一下麦克风说出来，自动转文字发送（浏览器支持时；需 HTTPS 或 localhost）。

## 边界守得住

| 场景 | 行为 |
| --- | --- |
| 要求代写作业 | 温和拒绝，引导说出卡点 |
| 提示注入（中英文越狱指令） | 拒绝改规则，并提醒学生可以直接指定档位/粒度 |
| 冒充老师索要答案 | 拒绝："身份没法验证，对所有人一个标准" |
| 表达轻生念头 | 先接住情绪，明确说自己只是助教，请立刻找班主任/辅导员/心理中心；**不给任何医疗建议** |
| 明显跑题 | 温和拉回课程 |
| 知识库外 | 直说"没收录"，不编造 |
| 空输入 / 纯表情 / 5000 字长文 / 错别字 | 不崩溃、不装懂 |

## 教师端

- `/teacher.html`：教师看板 —— 按课程、班级码、时间窗口查看
- 高频卡点 TOP3、档位分布、7 天趋势、课程分布、一条教学建议
- 一键生成 6 位班级码，学生填在首页；班级码不含任何个人信息
- 一键导出 CSV（带 BOM，Excel 直接打开）

## 快速开始

```bash
# 需要 Node.js >= 18（零第三方依赖，无需 npm install）
node server.js
# 学生端 http://localhost:3000
# 教师端 http://localhost:3000/teacher.html
```

不配置任何 API Key 也能完整运行：内置规则引擎可离线演示全部流程。

想接大模型（规则引擎定边界，大模型负责措辞）：

```bash
cp .env.example .env      # 填入 LLM_API_KEY（DeepSeek / OpenAI 兼容接口）
# Windows PowerShell:
$env:LLM_API_KEY="sk-..."; node server.js
```

配置后 `/api/health` 返回 `"mode":"llm+rule"`；大模型的输出会经过**档位护栏**：1/2 档出现代码会被自动剥离。

## 接口一览

| 接口 | 说明 |
| --- | --- |
| `POST /api/session` | 建会话（可带 `courseId`、`classCode`） |
| `POST /api/chat` | 对话（可带 `courseId`、`classCode`） |
| `POST /api/state` | 手动拨档位 / 粒度 |
| `POST /api/reset` | 重置会话状态 |
| `DELETE /api/session` | 删除会话（隐私） |
| `GET /api/courses` | 课程列表与知识量 |
| `GET /api/report?days=&course=&class=` | 教师周报 |
| `GET /api/report.csv` | 周报导出 |
| `GET /api/privacy` | 隐私与数据留存说明 |
| `GET /api/metrics` | 运行指标（Prometheus 文本格式） |
| `GET /api/health` | 健康检查 |

## 隐私设计

- 不收集姓名、学号、手机号；会话号是 12 位随机串
- 埋点只留问题类型、档位、课程、班级码，**不留原始输入**
- 会话 2 小时无活动自动回收；匿名埋点只存 7 天
- 教师报表只到班级/课程维度，不落到个人
- `DELETE /api/session` 可随时删除自己的会话

## 可选环境变量

| 变量 | 说明 | 默认 |
| --- | --- | --- |
| `PORT` | 监听端口 | `3000` |
| `LLM_API_KEY` | 大模型密钥（DeepSeek / OpenAI 兼容） | 空 = 纯规则引擎 |
| `LLM_BASE_URL` | 接口地址 | `https://api.deepseek.com` |
| `LLM_MODEL` | 模型名 | `deepseek-chat` |
| `ACCESS_CODE` | 访问码，填了才需要输入 | 空 = 开放访问 |
