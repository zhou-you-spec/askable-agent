# 部署与访问说明（京东云 JoyCode）

本项目是**零第三方依赖**的 Node.js 应用，只用到了 Node 内置模块，所以：

- 不需要 `npm install`
- 不需要数据库
- 不配置大模型也能完整跑通（内置规则引擎）
- 一个 `node server.js` 就能启动

## 一、在 JoyCode 里打开

**方式 A：导入 Git / 上传压缩包（推荐）**

1. 登录京东云 JoyCode，进入工作台
2. 新建项目 → 选择「导入已有项目」（或「上传本地代码」）
3. 上传 `askable-agent.zip`（或先推到 Git 再导入）
4. 项目类型选 **Node.js / Web 应用**
5. 启动命令填：`node server.js`（或 `npm start`）
6. 端口：`3000`（若平台注入 `PORT` 环境变量，代码会自动使用）

**方式 B：直接用容器镜像**

项目根目录已带 `Dockerfile`，在支持容器部署的环境里选择它即可，无需额外配置。

## 二、环境变量

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `PORT` | 否 | 平台注入则自动使用 |
| `LLM_API_KEY` | 否 | 不填 = 纯规则引擎（离线可演示）；填了 = 规则引擎 + 大模型润色 |
| `LLM_BASE_URL` | 否 | 默认 `https://api.deepseek.com` |
| `LLM_MODEL` | 否 | 默认 `deepseek-chat` |
| `ACCESS_CODE` | 否 | 填了才需要输入访问码 |

> 提交比赛建议：`ACCESS_CODE=demo`。这样提交表单里「账号 / 密码」可以填 **demo / demo**。
> 不填则任何人可直接打开，表单里写「无需登录」即可（以报名系统实际校验为准）。

## 三、一键部署 → 公网链接

1. JoyCode 里点「部署」/「发布」
2. 选择 Web 服务，确认端口与启动命令
3. 等待构建完成，拿到 `https://xxxx` 公网地址
4. 用手机扫码/直接打开，确认能进入对话页
5. 依次试：贴报错 → 点「再给点提示」→ 说「我放弃了」→ 打开右上角「教师周报」

## 四、部署后自检（30 秒）

| 检查项 | 预期 |
| --- | --- |
| `GET /api/health` | `{"ok":true,"mode":"rule"或"llm+rule"}` |
| 打开首页 | 出现「问不出口的那道题」与档位面板 |
| 发「什么是 pip」 | 先给应用商店类比，不出现代码 |
| 发「再给点提示」 | 档位升到 2 档，仍无代码 |
| 发「我放弃了」 | 给完整代码 + 逐行讲 |
| 点右上「教师周报」 | 出现 TOP3 卡点与档位分布 |

## 五、常见问题

- **启动报端口占用**：换端口 `$env:PORT=3001; node server.js`
- **页面能开但发消息无响应**：多半是平台没设置 `PORT` 注入，检查健康检查路径 `/api/health`
- **配置了 Key 但仍是纯规则**：确认变量名是 `LLM_API_KEY`（也兼容 `DEEPSEEK_API_KEY`），重启后看 `/api/health` 的 `mode`
- **想换课程**：只改 `knowledge/` 下四个 JSON，机制不用动
